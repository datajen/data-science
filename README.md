# data-science
The R browseURL function in RStudio takes you to University of Missouri's extracurricular club, Women C.A.N. (Computers and Networking), *website and instagram pages.
I co-founded Women C.A.N. in 2017 as an undergraduate student in the computer science program.
Run the program, or copy and paste the URL in your browser to check out what the club is up to today!
*Website is no longer active. Instagram is active.
